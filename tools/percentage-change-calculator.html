Percentage Change Calculator

Calculate percentage increase or decrease between two values.

Using the Percentage Change Calculator

Use the Percentage Change Calculator to measure the percentage increase or decrease between an original value and a new value.

How the Percentage Change Calculator works

Enter the original and new values. A zero original value cannot produce a conventional percentage-change result, so the calculator validates that case.

Important details and limitations

Percentage change compares the difference with the original value. A positive result indicates an increase and a negative result indicates a decrease.

Practical guidance

For business or scientific work, keep the original units and precision alongside the percentage so the result is not taken out of context.
