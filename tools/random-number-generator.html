Random Number Generator

Generate a secure random integer in your browser.

Using the Random Number Generator

Use the Random Number Generator to produce a cryptographically strong random integer within a supported range directly in the browser.

How the Random Number Generator works

Enter a minimum and maximum whole number and generate a value. The tool rejects invalid ranges and requires the browser's Web Crypto API.

Important details and limitations

The generator uses rejection sampling to avoid introducing a simple modulo bias for supported ranges. It is intended for practical randomization, not as a substitute for a reviewed security protocol.

Practical guidance

Keep the requested range within the tool's documented limits and never assume a random number alone provides security for an application design.
