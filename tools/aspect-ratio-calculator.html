Aspect Ratio Calculator

Calculate the simplified aspect ratio from width and height.

Using the Aspect Ratio Calculator

Use the Aspect Ratio Calculator to reduce a width and height pair to its simplest ratio.

How the Aspect Ratio Calculator works

Enter positive whole-number dimensions such as 1920 by 1080. The calculator uses the greatest common divisor to simplify the pair.

Important details and limitations

Aspect ratio describes proportional width and height. A ratio such as 16:9 can help when preparing images, video frames, presentations or responsive media.

Practical guidance

The result does not resize an image itself. Use the Image Resizer when you need to create a new file with different pixel dimensions.
