How to Calculate Percentages: Formula, Examples and Common Mistakes

Percentages express a quantity as parts per hundred. This guide shows the main percentage formulas, worked examples and checks you can use before relying on a result.

The basic percentage formula

To find what percentage one value is of another, divide the part by the whole and multiply by 100.

Percentage = (part ÷ whole) × 100

For example, if 25 students out of a class of 200 completed an exercise, the percentage is (25 ÷ 200) × 100 = 12.5%.

Find a percentage of a number

To find a percentage amount, convert the rate to a decimal and multiply it by the base value. For 15% of 240, calculate 0.15 × 240 = 36.

Work backwards from a percentage

If you know the percentage and the resulting amount, divide the amount by the decimal form of the percentage. If 20% of a number is 50, the original number is 50 ÷ 0.20 = 250.

Percentage increase and decrease

For a change between an original and a new value, use ((new − original) ÷ original) × 100. An increase from 80 to 100 is a 25% increase. A decrease from 100 to 80 is a 20% decrease. The base value matters, so the two directions are not symmetrical.

Common mistakes

  • Confusing 15% with 15 as a decimal. The decimal form of 15% is 0.15.
  • Using the wrong base when calculating percentage change.
  • Mixing units, such as comparing monthly revenue with annual revenue.
  • Rounding too early and then using the rounded value in later calculations.
  • Dividing by zero when the whole or original value is zero.

Quick sanity checks

A percentage-of-value result should usually scale with the base number. A percentage change also needs a clearly defined original value. If the result looks unexpectedly large or negative, check the sign, units and denominator before assuming the calculation is wrong.
