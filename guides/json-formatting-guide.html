JSON Formatting and Validation: Syntax, Examples and Errors

JSON is a text format used to represent structured data. Formatting makes JSON easier to read, while validation checks whether the text follows JSON syntax.

A minimal JSON object

A JSON object uses braces and quoted property names. For example:

{"name":"UtilityHub","count":28}

Whitespace can be added for readability without changing the represented values.

Objects and arrays

Objects contain name-value pairs. Arrays contain ordered values inside square brackets. Values can be strings, numbers, booleans, null, objects or arrays.

{"tools":["Percentage Calculator","JSON Formatter"],"free":true}

Common syntax errors

  • Using single quotes instead of JSON double quotes for strings and property names.
  • Leaving a trailing comma after the last item in an object or array.
  • Forgetting a closing brace or bracket.
  • Using an unquoted word where JSON expects a string, boolean, number or null.
  • Including comments, which standard JSON does not support.

Formatting versus validation

Formatting changes whitespace and indentation so valid JSON is easier to inspect. Validation determines whether the input can be parsed as JSON. A formatter should not be treated as a data-quality checker: syntactically valid JSON can still contain incorrect values for your application.

Work safely with sensitive data

When a tool supports local processing, keeping ordinary input in the browser can reduce unnecessary transfers. You should still follow your organization's data-handling rules and avoid placing secrets, credentials or confidential records into tools unless their handling is appropriate.

Use the JSON Formatter

Use UtilityHub's JSON Formatter to validate and pretty-print JSON in the browser. If the formatter reports an error, inspect the location and check quotes, delimiters and commas first.

Important limitation

Valid JSON only establishes syntax. It does not prove that a document matches an API schema, contains correct business values or is safe for a particular application.
