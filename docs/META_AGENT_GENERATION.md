# UtilityHub Meta-Agent Generation System

Converts a high-level engineering mission into a bounded, auditable team of specialized agent missions. It is an orchestration layer, not an unrestricted self-modifying agent.

Roles: Architect, Implementer, QA, Security, Performance, SEO, Growth, Monetization, Verifier.

Contract: Discover -> architecture review -> implementation -> QA -> security -> specialist reviews -> independent verification -> focused PR.

Required roles are always generated. Optional roles are selected by focus or all.

Safety: no test weakening, deletion or hiding; no direct main merge; no production certification without live evidence; no fabricated traffic, revenue, partnerships, approvals or compatibility; critical security findings stop orchestration; repeated verification failures stop rather than looping indefinitely.

Activation: run the GitHub Actions workflow UtilityHub Meta-Agent Generation with a concrete mission, risk level and optional focus. It creates a mission-pack artifact and traceable GitHub issue. Actual agent execution requires an available agent runtime/delegation mechanism.
